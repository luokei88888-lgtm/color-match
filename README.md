# 彩珠消消

竖屏三消小游戏。玩法参考主流 Match-3（三连消除、连锁、特殊棋子、关卡目标），美术与关卡为原创实现，不是任何商业游戏的翻版。

支持浏览器游玩，也可以用 Electron 打成 Windows 安装包。

仓库：[https://github.com/luokei88888-lgtm/color-match](https://github.com/luokei88888-lgtm/color-match)

## 功能概览

- **30 关冒险地图**：逐步解锁，通关记录保存在浏览器本地
- **三种关卡目标**：达到分数、打碎冰块、收集指定颜色
- **限时关**：第 5 / 10 / 15 / 20 / 25 / 30 关改为倒计时，不限步数
- **特殊棋子**：4 连直线、5 连炸弹、L/T 型炸弹、同色炸弹；特殊棋子互碰有组合效果
- **道具**：锤子（砸一格）、重排棋盘、+5 步
- **七套美术主题**：可随时切换，选择会记住
- **音效**：Web Audio 程序化合成，无需音频文件；对局页可静音
- **桌面安装包**：Windows NSIS 安装程序，装完可从桌面快捷方式打开

## 怎么玩

1. 点「开始冒险」进入关卡地图，点已解锁的关卡开打。
2. 点两颗**相邻**彩珠交换。能形成 3 颗及以上同色连线才会交换成功。
3. 消除后上方棋子下落，可能触发连锁。连消越多分数越高。
4. 在步数用完（或倒计时结束）前完成关卡目标即过关；否则失败，可重试。

### 特殊棋子

| 合成方式 | 效果 |
| --- | --- |
| 4 连 | 直线消除整行或整列 |
| 5 连 | 同色炸弹，清掉盘上该颜色 |
| L / T 型 | 范围炸弹，炸掉周围一圈 |

两颗特殊棋子交换会打出更强的组合（双直线、直线+炸弹、双同色炸弹等）。

### 道具

| 道具 | 作用 |
| --- | --- |
| 锤子 | 进入瞄准模式，点一格直接砸掉（可砸冰块） |
| 重排 | 打乱当前棋盘 |
| +5 步 | 增加 5 步（限时关仍走步数逻辑，但过关看时间） |

新号默认各 3 个。一关拿到 **2 星及以上** 会额外奖励 1 个道具。

### 星星怎么算

过关后按**本局最终分数**对照该关三个分数门槛，够到几档就几颗星。地图上显示的是该关历史最好成绩。

举例（第 1 关）：门槛约 950 / 1700 / 2750 分。刚够目标分数通常 1 星；连锁和特殊棋子刷高分可拿 2～3 星。

### 关卡节奏

| 关卡 | 类型 |
| --- | --- |
| 1–5 | 分数目标（第 5 关限时） |
| 6–10 | 打碎冰块（第 10 关限时） |
| 11–15 | 收集指定颜色（第 15 关限时） |
| 16–20 | 更高分数、6 色棋盘 |
| 21–25 | 更密的冰块 |
| 26–30 | 收集挑战 |

## 美术主题

首页或地图右上角「🎨」打开主题面板。当前主题存在 `localStorage`。

| 主题 | 说明 |
| --- | --- |
| 数码大冒险 | 默认。数码宝贝角色头像棋子（程序绘制，非官方素材） |
| 光之英雄 | 奥特曼与怪兽头像棋子（程序绘制，非官方素材） |
| 皇家王国 | 蓝金王冠、盾牌、金币 |
| 糖果甜品 | 糖纸、棒棒糖、软糖 |
| 花园治愈 | 草莓、向日葵、水果 |
| 卡通轰趴 | 描边方块 + 图标 |
| 国风雅致 | 灯笼、元宝、梅花、玉环 |

棋子纹理用 Canvas 2D 在运行时烘焙，不依赖外部图片资源。

> 数码宝贝、奥特曼等角色形象属于对应权利方。本仓库中的造型是自行绘制的示意头像，仅供个人学习，**不要拿去公开发售或商用**。

## 技术栈

| 层 | 选型 |
| --- | --- |
| 语言 | TypeScript |
| 构建 | Vite 6 |
| 渲染 / 场景 | Phaser 3 |
| 单测 | Vitest（只测 `src/core`，不依赖 Phaser） |
| 桌面包 | Electron 43 + electron-builder（Windows NSIS） |
| 存档 | `localStorage`（进度、音量、主题） |

核心规则（生成棋盘、匹配、下落连锁、特殊棋子、冰块、道具）都在 `src/core/`，场景层只负责输入、动画和 HUD。

## 目录结构

```
color-match/
├── electron/main.cjs      # 桌面窗口：加载 dist/index.html
├── src/
│   ├── main.ts            # Phaser 入口，启动时恢复主题
│   ├── core/              # 纯逻辑：棋盘、匹配、关卡、道具
│   ├── data/levels/       # 30 关配置
│   ├── game/              # Boot / Map / Play / Result 场景
│   ├── art/               # 调色板、造型库、纹理烘焙、特效
│   ├── audio/sfx.ts       # 程序化音效
│   ├── ui/themePicker.ts  # 主题选择面板
│   └── storage/progress.ts
├── tests/core/            # 棋盘与关卡单测
├── index.html
├── package.json
└── release/               # 打包产物（不进 Git）
```

## 环境要求

- Node.js 18+（建议 20）
- Windows 上打安装包需要能下载 Electron 二进制（国内可配镜像）

## 本地开发

```bash
npm install
npm run dev
```

默认 http://127.0.0.1:5173 。

```bash
npm test          # 跑一遍单测
npm run test:watch
npm run build     # 类型检查 + 产出 dist/
```

## 打 Windows 安装包

```bash
npm run app:dist
```

会先执行网页构建，再用 electron-builder 生成：

```
release/ColorMatch-Setup-1.0.0.exe
```

双击安装，会创建桌面和开始菜单快捷方式「彩珠消消」。只想本地用 Electron 窗口预览、不打安装包：

```bash
npm run build
npm run app:start
```

国内网络若下载 Electron 失败，可先设置镜像再打包：

```powershell
$env:ELECTRON_MIRROR='https://npmmirror.com/mirrors/electron/'
$env:ELECTRON_BUILDER_BINARIES_MIRROR='https://npmmirror.com/mirrors/electron-builder-binaries/'
npm run app:dist
```

未购买代码签名证书时，Windows 可能弹出 SmartScreen 提示，选「更多信息 → 仍要运行」即可。

## 存档说明

| 键 | 内容 |
| --- | --- |
| `color-match-progress-v1` | 解锁进度、每关星数、道具数量、音量 |
| `color-match:theme` | 当前主题 ID |

清档：浏览器开发者工具里删掉上述项，或重装后清站点数据。桌面版同样走 Chromium `localStorage`。

进度写入有大小上限（32 KB），避免异常膨胀。
